# Contribuire a FustellaLab

- Crea un branch `feature/nome-funzione` o `fix/nome-problema`.
- Prima di proporre una modifica, esegui `python3 -m unittest discover -s tests -v`.
- Non committare database, file dei clienti, credenziali o output di produzione.
- Non dichiarare una fustella pronta per il taglio senza collaudo dimensionale e macchina.
- Ogni funzione va descritta come implementata, sperimentale o pianificata.
